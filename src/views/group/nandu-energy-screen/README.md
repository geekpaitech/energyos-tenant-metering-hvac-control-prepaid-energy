# 南都广场智慧能源管理大屏

第一版为独立的场景式能源展示页面。仅使用固定模拟数据，不请求管理方接口，不增加导航菜单或按钮入口。

## 访问

在现有系统登录后，直接访问 `/#/group/nandu-energy-screen`。保留原有 `/group/energy-screen`。

页面基准为 1920 × 1080，按容器视口等比缩放；非 16:9 屏幕居中留边，不裁切楼体、数据或标注。

## 文件

- `index.vue`：页面组合、场景加载、交互、缩放、动画状态。
- `screen.scss`：全部样式限定在 nandu 命名空间，无全局覆盖。
- `data.js`：项目配置、场景坐标、模拟快照、数据加载适配口。
- `components/`：图标、趋势图、能源流向、建筑标注。
- `assets/nandu-night-scene.png`：独立背景（1672 × 941），楼体竖牌为“南都广场”。
- `assets/prompt.txt`：使用内置 imagegen 生成背景的提示词记录。
- `assets/icons/`：Material Design Icons 原始 SVG 资源及许可证。

## 数据口径

这是截至 2026-09-17 10:30 的固定演示快照，不代表真实业务数据。

- 本月为 9 月 1 日至 17 日累计，近 7 日曲线为截至 16 日的完整日数据。
- 项目用电 286,600 = 租户 218,600 + 公区 68,000 = 市电购入 270,800 + 光伏自用 15,800（kWh）。
- 光伏发电 18,600 = 自用 15,800 + 上网 2,800（kWh）。上网电量不计入项目用电。
- 租户用电 = 室内用电 153,020 + 空调用电 65,580（kWh）。
- 设备 584 台 = 在线 570 + 离线 14；空调内机 216 = 运行 148 + 待机 62 + 离线 6。
- 应收 264,500 = 实收 253,920 + 未收 10,580（元）。
- 比例由基础数值计算，展示时四舍五入。
- 建筑热点只说明位置；不把项目汇总伪装成某栋楼/某层的实际数据。

后续确认管理方后，将 `loadScreenSnapshot()` 替换为接口适配，保持展示结构；同时明确接口的单位、统计范围、时间边界、缺失值与状态定义。

## 展示行为

背景加载后执行一次轻入场；能源流向与标注保留低频动画。尊重系统“减少动态效果”，页面在后台时暂停动画。图表、监听器在页面销毁时释放。点击建筑标注或“演示数据”可查看说明，支持 Esc 关闭和键盘焦点返回。
